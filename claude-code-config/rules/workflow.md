# 工作流程规范

## Plan First
- 非简单任务（3+ 步骤/多文件/不确定方案）先用 plan mode 写计划再动手
- 简单任务（改错字、加日志、重命名）直接做，不用规划
- 执行中发现计划不对，立即停下来重新规划，不要硬撑

## 验证再完成
- 不要口头说"已完成"，要贴证据：测试结果、命令输出、diff
- 没有验证手段的任务，主动告诉用户"我无法验证这个改动"

## Self-Improvement
- 被用户纠正 2 次以上同样的问题 → 更新对应 rules 文件
- 发现非显而易见的坑 → 写入 rules 而不是只记在对话里

## Subagent 策略
- 代码库探索、文件搜索等消耗上下文的工作 → 交给 subagent
- subagent 返回摘要，不污染主对话上下文
- 需要第二意见的验证 → 用独立 subagent 做 adversarial review
